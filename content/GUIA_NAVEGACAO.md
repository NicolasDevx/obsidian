# 🗺️ Guia de Navegação — AuraCamp

Bem-vindo ao sistema de análise eleitoral da **Dra. Cristiany — Eleições 2026**.
Este guia explica como navegar pelo site e acessar cada funcionalidade.

---

## 🏠 Página Inicial

Ao acessar o site, você verá a página inicial com os principais links.
Use a **barra lateral esquerda** para navegar entre as seções.

---

## 📂 Estrutura do Site

| Seção | O que tem lá |
|-------|-------------|
| 📁 **Candidatos** | Perfil da Dra. Cristiany, dados de 2022 por cidade |
| 📊 **Análises** | Análises estratégicas para 2026 |
| 🏛️ **AuraCamp** | Sobre o sistema |

---

## 🔍 Como Navegar

### 1. Barra lateral esquerda
- Clique nas **pastas** para expandir e ver os arquivos dentro
- Clique em qualquer **nota** para abrir

### 2. Links internos
- Palavras em **azul/verde** são links clicáveis para outras notas
- Clique neles para navegar entre os conteúdos relacionados

### 3. Breadcrumbs (trilha no topo)
- No topo de cada página aparece:  
  `Home ❯ Candidatos ❯ Dra. Cristiany ❯ ...`
- Clique em qualquer parte para voltar

---

## 📈 Como Abrir o Gráfico (Grafo)

O **grafo** mostra como todas as notas estão conectadas entre si.

### Grafo Local (pequeno — lado direito)
- Fica visível na **barra lateral direita** de cada página
- Mostra as conexões da nota atual com outras notas próximas
- 🖱️ **Passe o mouse** sobre um nó para destacar as conexões
- 🖱️ **Clique** em um nó para navegar até aquela nota

### Grafo Global (completo — todas as notas)
- Clique no **ícone de rede** 🕸️ no canto do grafo local
- Ou pressione **Ctrl + G** no teclado
- Mostra **todas** as notas e suas conexões
- 🖱️ **Arraste** para mover o grafo
- 🖱️ **Scroll** para dar zoom
- 🖱️ **Clique** em qualquer nó para abrir a nota

## 📊 Páginas Importantes

### 🏆 Painel Geral das Eleições 2022
> Candidatos → Dra. Cristiany → Eleições 2022 — Painel Geral

Contém:
- Top 10% das cidades mais votadas (65 municípios)
- Top 30% (194 municípios)
- Cidades com **zero votos** — prioridade 2026
- Cidades com base forte (acima de 200 votos)

### 🎯 Análise de Oportunidades 2026
> Análises → Análise — Oportunidades 2026

Contém:
- Municípios com **zero votos** — territórios virgens
- Municípios com **1 a 50 votos** — potencial de crescimento
- Base forte — municípios acima de **500 votos**

### 👤 Perfil da Candidata
> Candidatos → Dra. Cristiany → Dra. Cristiany — Perfil

---

## 🏷️ Como usar as Tags

No topo de cada nota há **tags** coloridas (ex: `#analise`, `#2026`).
- Clique em uma tag para ver **todas as notas** com aquela tag
- Útil para filtrar por tema
