# 🚀 AuraCamp — Sistema de Gestão Eleitoral

## O que é
O **AuraCamp** é um CRM Eleitoral Multi-Tenant desenvolvido para gerenciar campanhas eleitorais de múltiplos candidatos e agências.

## Stack Técnica
- **Frontend:** Next.js + TypeScript
- **Backend:** FastAPI (Python)
- **Banco de dados:** PostgreSQL (multi-schema)
- **Infra:** Docker + Docker Compose
- **Auth:** JWT + controle por tenant

## Módulos previstos
- [ ] Login multi-tenant (Owner / Agência / Candidato)
- [ ] Gestão de candidatos
- [ ] CRM de eleitores
- [ ] Lideranças regionais
- [ ] Relatórios semanais
- [ ] Painel executivo
- [ ] Análise de dados eleitorais (integração TSE)
